## 💭 Why I Started This

This project began from something personal.

I often find myself thinking in fragments instead of sentences. Ideas branch into other ideas. A memory reminds me of another. A simple observation somehow connects to something completely different.

Trying to force those thoughts into linear notes always felt wrong. Sometimes writing itself becomes difficult.

But drawing a circle... adding a few words... scribbling around it... connecting things naturally — that feels effortless.

MindCanvas exists because I wanted software that disappears and lets me think. If it helps someone else organize their thoughts, calm their mind, brainstorm a project, prepare for an exam, or simply understand themselves a little better, then this project has already succeeded.

---

## 🪶 Philosophy

> The interface should disappear. The canvas should become the experience.

The software should never tell users **how** to think. Instead, it should quietly adapt to however they naturally express themselves.

## 🧭 Core Principles

| | |
|---|---|
| ♾️ **Infinite canvas** | No edges, no limits |
| ✍️ **Mouse, touch & stylus first** | Draw however feels natural |
| 💾 **Local-first** | Your data lives on your device |
| 🔒 **Privacy-first** | Nothing leaves your machine unasked |
| 📴 **Offline-first** | Works with zero connection |
| ⚡ **Invisible speed** | Fast enough to disappear |
| 🚫 **No AI interpretation** | Your thoughts stay yours |
| 🚫 **No forced node graphs** | Structure emerges, it isn't imposed |
| 🚫 **No unnecessary complexity** | Just a canvas and a pen |

## ✨ Features

### Infinite Canvas
- Unlimited workspace
- Smooth pan & zoom
- High-performance rendering

### Natural Thinking
Scribbling · Drawing · Handwriting · Typed text · Free placement

No rigid hierarchy. No forced structure.

### 🖊️ Drawing Tools

`Pen` · `Pencil` · `Brush` · `Highlighter` · `Eraser` · `Text` · `Hand Tool` · `Lasso Selection`

### 📤 Export

Take your thoughts anywhere:

| Format | Use case |
|---|---|
| **PNG** | Quick sharing |
| **PDF** | Printing & archiving |
| **SVG** | Scalable, editable |
| **JSON** | Full-fidelity backup |
| **Share Link** | Secure, on-demand |

Nothing is uploaded automatically.

### 🔐 Privacy

Your thoughts belong to you. MindCanvas stores everything locally by default.

**No accounts · No telemetry · No hidden cloud sync · No tracking**

## 🎨 Design Goals

Instead of looking like productivity software, MindCanvas should feel like:
